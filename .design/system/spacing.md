# Spacing System & Border Radius Scale (/KUI:system)

## 8px Base Scale

Every dimension adheres strictly to multiples of 4 or 8:
- `xs` (4px): Icon-text inline gap, tag inner vertical padding
- `sm` (8px): Filter chip gap, between related stat elements
- `md` (12px): Section label bottom margin, table cell padding
- `base` (16px): Standard container padding, button horizontal padding
- `lg` (24px): Card internal padding, section label top margin
- `xl` (32px): Major group separation, bento grid row spacing
- `xxl` (48px): Hero vertical padding (mobile), section vertical spacing
- `xxxl` (64px / 80px): Section vertical padding on desktop

## Border Radius Scale
- `xs` (4px): Tiny tag indicators, code snippets
- `sm` (8px): Small badges, calculator quantity stepper
- `md` (12px): Standard buttons, search inputs, dropdowns
- `lg` (16px): Bento cards, service rate cards, FAQ containers
- `xl` (20px / 24px): Hero Google auth card
- `full` (9999px): Pills, category filter chips, theme switcher
