# Typography Scale (/KUI:system)

Following Apple Human Interface Guidelines and Killer UI standards:

| Level | Size | Weight | Line Height | Tracking | Purpose |
|-------|------|--------|-------------|----------|---------|
| **Display** | 48px (sm: 52px) | 900 (Black) | 1.1 | -1.5px | Hero Title |
| **Large Title** | 34px | 800 (ExtraBold) | 1.15 | -1.0px | Major Section Headlines |
| **Title 1** | 28px | 800 (ExtraBold) | 1.2 | -0.75px | Card Group Titles |
| **Title 2** | 22px | 700 (Bold) | 1.25 | -0.4px | Subsection & Bento Card Titles |
| **Headline** | 17px | 600 (SemiBold) | 1.3 | -0.2px | List Titles, Button Labels |
| **Body** | 16px | 400 (Regular) | 1.5 | -0.1px | Hero Description, FAQ Answers |
| **Callout** | 15px | 400 (Regular) | 1.45 | 0 | Sub-copy, Helper Text |
| **Subheadline** | 14px | 500 (Medium) | 1.4 | 0 | Secondary Card Metadata |
| **Footnote** | 13px | 400 (Regular) | 1.4 | 0 | Timestamps, Secondary Labels |
| **Caption** | 11px | 700 (Bold) | 1.3 | +0.8px | Section Overlines (UPPERCASE) |
| **Mono** | 13-14px | 700 (Bold) | 1.4 | 0 | Prices, Speed benchmarks, Uptime |
