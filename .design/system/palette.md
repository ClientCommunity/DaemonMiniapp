# Color Palette System (/KUI:system)

## 1. Brand & Semantic System

The Deamon OTP UI palette employs a restrained, high-contrast mathematical foundation:
- **Primary Brand:** Electric Violet (`#7c3aed`), conveying developer-grade precision and power without chaotic neon wash.
- **Accent:** Cyan/Sky (`#38bdf8` in Dark, `#0284c7` in Light) for protocol delivery information and telegram bot callouts.
- **Success:** Emerald (`#22c55e` in Dark, `#16a34a` in Light) for arrival speeds, operational uptime, and refund guarantees.
- **Warning / Refill:** Amber (`#f59e0b` in Dark, `#d97706` in Light).

## 2. Light & Dark Paired Tokens

| Token | Light Mode | Dark Mode | Purpose |
|-------|------------|-----------|---------|
| `bg` | `#f8fafc` (slate-50) | `#090a0f` (deep matte) | Page canvas background |
| `surface` | `#ffffff` (pure white) | `#12131a` (architectural dark) | Card containers, modal boxes |
| `surface-elevated` | `#f1f5f9` (slate-100) | `#181924` (elevated slate) | Interactive tags, calculator containers |
| `border` | `#e2e8f0` (slate-200) | `#1f202b` (subtle dark border) | Card borders, section separators |
| `border-strong` | `#cbd5e1` (slate-300) | `#2d2f3d` | Hover borders, active inputs |
| `text-primary` | `#0f172a` (slate-900) | `#ffffff` (clean white) | Headings, main numbers, titles |
| `text-secondary` | `#475569` (slate-600) | `#94a3b8` (slate-400) | Explanatory copy, item descriptions |
| `text-tertiary` | `#64748b` (slate-500) | `#64748b` (slate-500) | Captions, timestamps, metadata |
